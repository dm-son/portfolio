About

Rakeen 고객 포털 신규 서비스 개발

"비즈니스 목표를 위해 기술적 욕심보다 최적화를 선택하다"

사우디 현지 기업(SITE)을 위한 고객 포털 구축 당시, 저에게 주어진 과제는 반기 내 런칭과 불안정한 현지 인프라 극복이었습니다. 기존의 복합적인 MSA와 K8s 구조를 고집하기보다, 운영 안정성을 최우선으로 판단하여 Docker Compose 기반의 모놀리식 구조로 아키텍처를 과감히 단순화했습니다.
단순히 구조만 바꾼 것이 아니라, 고객사 Keycloak과의 연동 과정에서 발생하는 보안 공백을 메우기 위해 Public Client 기반 JWKS 검증 체계와 HMAC API 인증 구조를 직접 설계했습니다. 또한, 물리적 거리로 인한 파일 다운로드 지연을 해결하고자 기존 NAS 방식을 AWS S3로 전환하며 성능 최적화를 이뤄냈습니다.
백엔드 핵심 영역의 70%를 직접 수행하며 기술적 의사결정을 주도한 결과, 데드라인을 준수하며 안정적으로 서비스를 오픈했고 해당 연도 인사평가 최상위 등급을 달성했습니다.

MyCompany B2B 서비스 운영

"인프라 고도화를 통해 지속 가능한 서비스 기반을 구축하다"

기존 VM 기반의 배포 환경을 서비스 확장성과 운영 효율을 극대화하기 위해 MyCompany 및 주요 MSA 서비스를 Docker/K8s 기반으로 전환했습니다. 컨테이너 단위의 리소스 격리와 환경 일관성을 통해 서비스 안정성과 확장성을 동시에 달성했습니다.
비즈니스 측면에서는 고객사마다 다른 조직 구조를 뒷받침하기 위해 권한 위임 모델을 설계하고 구현하여 비즈니스 확장성을 확보했습니다.
또한, 별도로 운영되던 Zendesk 기반 고객 지원 서비스와 안랩닷컴 패밀리사이트를 SSO로 연동하여, 사용자가 단 한 번의 로그인으로 고객 지원까지 끊김 없이 이용할 수 있는 통합 인증 체계를 완성했습니다.
단순 유지보수에 그치지 않고 실시간 로그 분석을 바탕으로 한 코드 레벨 리팩토링을 지속하며, 기업 고객이 언제나 믿고 사용할 수 있는 견고하고 안정적인 서비스 기반을 다져왔습니다.

안랩닷컴 고도화

"외부 SSO 솔루션을 걷어내고 자체 인증 구조를 구축하다"

기존 안랩닷컴은 JSP 기반 서비스이고 상용 SSO 솔루션에 의존하고 있어, 새로운 요구사항이 생길 때마다 기술 부채와 외부 지원에 의존해야 하는 비효율적인 구조였습니다. 이를 해결하기 위해 Spring Boot 기반의 독립적인 인증 마이크로서비스로의 고도화를 추진했습니다.
가장 큰 도전은 분산 서버 환경에서 기존 세션 방식을 대체하는 것이었습니다. 이를 위해 JWT 기반 인증 체계를 직접 설계하고, 토큰 갱신 시 발생하는 병목 현상을 해결하고자 Redis를 도입하여 In-memory 기반 인증 처리 구조를 확립했습니다. 이 과정을 통해 외부 솔루션 의존성을 완전히 제거하고, 우리 서비스에 최적화된 고성능 인증 기반을 내재화할 수 있었습니다.

국가공간정보센터 K-Geo플랫폼 구축

"환경의 한계를 넘어 현대적 UX를 구현하다"

정부 주도 SI 프로젝트의 기술적 제약(JSP 기반) 안에서 사용자 응답성과 UX를 개선하기 위해 SPA 구조를 설계하고, 효율적인 개발을 위한 이벤트 기반 프론트엔드 공통 모듈을 직접 개발했습니다. 단순히 화면을 구성하는 데 그치지 않고, 오픈소스 라이브러리를 활용한 데이터 시각화와 Websocket 기반의 실시간 데이터 갱신 기능을 구현해 사용자에게 정보를 직관적으로 전달하는 데 집중했습니다.
백엔드 측면에서는 기능별 REST API와 CRUD 로직을 설계했으며, 리포팅 툴 연동을 통한 보고서 출력 및 대용량 엑셀 업/다운로드 기능을 안정적으로 구현했습니다. 또한 Spring Scheduler를 활용해 자동화 알림 시스템을 구축함으로써 업무 편의성을 높였습니다.
레거시 환경에서도 최신 웹 기술의 장점을 녹여내어, 플랫폼에 접속한 사용자가 더 빠르고 편리하게 탐색할 수 있는 기반을 마련했습니다.
