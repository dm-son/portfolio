About

Rakeen 고객 포털 신규 서비스 개발

MyCompany B2B 서비스의 기존 소스코드를 기반으로, 해외 고객 환경에 최적화된 서비스를 구축하는 프로젝트예요. 앞선 MyCompany 서비스 운영 경험을 바탕으로 기술적 의사결정과 리드를 맡아 진행했어요.
Keycloak 기반 인증 시스템과 고객 서비스 포털의 JWT 인증을 연계하는 과정에서 외주 프론트엔드 업체와 협업해 안정적인 인증 환경을 구축했어요.
해외 운영 환경에서 네트워크 부하를 줄이기 위해 기존 MSA 아키텍처를 모놀리식 구조로 마이그레이션했고, 보안 취약점 개선을 위해 Spring Boot와 Java 버전을 업그레이드하면서 Maven에서 Gradle로 전환했어요. 또한 HMAC 인증 메커니즘을 적용해 제품 인증 API 통신 보안을 강화하고, NAS 기반 파일 다운로드 방식을 AWS S3로 개선해 성능을 최적화했어요.

MyCompany B2B 서비스 운영

MyCompany는 고객이 제품 파일을 다운로드하고 오프라인 인증을 수행하며 사용량과 계약 정보를 조회할 수 있는 B2B 플랫폼이에요. 이 서비스를 담당하면서 SMS·이메일 기반 2단계 인증을 적용해 보안을 강화했고, DevOps와 협업해 일부 MSA 서비스를 Docker·Kubernetes 기반 컨테이너 환경으로 전환해 운영 효율성을 높였어요. 또한 오프라인 인증 과정에서 고객 간 권한 위임이 가능하도록 테이블 구조를 설계하고 구현했어요. 장애 발생 시엔 실시간 로그와 쿼리 분석으로 빠르게 대응하며 안정성을 확보했고, 유관 부서와 협력해 고객 요구사항을 지속적으로 서비스에 반영해 나갔어요.

안랩닷컴 고도화

안랩닷컴은 레거시(JSP) 환경에서 한컴위드의 SafeIdentity 솔루션 기반으로 SSO를 운영해왔는데, 타사 솔루션에 의존하다 보니 요구사항을 유연하게 반영하기 어려웠어요. 이를 해결하기 위해 안랩닷컴 서비스를 Spring Boot 기반으로 고도화하면서 인증 도메인을 분리하고, JWT 기반 인증 체계를 직접 설계 및 구현했어요. 분산 환경에서의 토큰 갱신을 위해 Redis를 도입하면서 In-memory DB 활용 경험도 쌓았어요.

국가공간정보센터 K-Geo플랫폼 구축

정부 주도 SI 프로젝트로, JSP 환경에서 SPA 구조를 설계하고 이벤트 기반 프론트엔드 공통 모듈을 개발했어요. 오픈소스 라이브러리를 활용해 데이터 시각화와 웹소켓 기반 실시간 데이터 갱신 기능도 구현했어요.
기능별 CRUD 및 REST API를 설계·개발했고, 리포팅 툴과 연동해 보고서 출력과 엑셀 업로드/다운로드 기능을 구현했어요. 또한 Spring 스케줄러를 활용해 자동화 알림 시스템을 구축했어요.
